Задание: Подними GitLab CI или GitHub Actions с уязвимым пайплайном (например, скрипт деплоя получает branch name и подставляет в команду без экранирования). Выполни command injection и получи секреты из Variables.
Dependency Confusion: Подними локальный PyPI-сервер, создай пакет с именем, как у внутреннего, и добейся, чтобы CI его подхватил.
IaC Scanning: Научись писать проверки для Terraform (Checkov, tfsec) и понимать, какие небезопасные конфигурации они находят.
