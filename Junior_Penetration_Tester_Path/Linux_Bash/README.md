Неделя 1: Установка и базовое выживание 
Задача 1.1: Установить Ubuntu Server 22.04 LTS на виртуальную машину (VirtualBox). Выдели 2 ГБ ОЗУ, 20 ГБ диска. При установке выбери OpenSSH сервер.

Проверка: После установки залогинься в черный экран. Выполни sudo apt update && sudo apt upgrade -y. Перезагрузи sudo reboot. Убедись, что SSH работает: с хостовой машины подключись через ssh username@IP_виртуалки.
Задача 1.2: Освой навигацию. Создай структуру папок /home/твой_юзер/pentest/labs. Внутри создай подпапки recon, exploits, wordlists. Используй только команды mkdir, cd, ls.

Проверка: Выполни tree ~/pentest (если нет tree, установи sudo apt install tree) и покажи вывод.
Задача 1.3: Создай файл notes.txt в папке ~/pentest с помощью редактора Vim. Открой его (vim notes.txt), нажми i, напиши «Я начинаю путь пентестера», нажми Esc, потом :wq. Просмотри содержимое cat notes.txt.

Ресурс: Встроенный тутор vimtutor (запусти в терминале).
Неделя 2: Потоки, пайпы, права
Задача 2.1: Перенаправление. Выполни ls -la /etc > ~/pentest/etc_list.txt. Затем добавь вывод команды date в конец того же файла: date >> ~/pentest/etc_list.txt.

Проверка: Прочти файл cat ~/pentest/etc_list.txt, убедись, что там список и дата.
Задача 2.2: Пайпы и grep. Найди все строки с «error» в системном логе: cat /var/log/syslog | grep -i error. Теперь найди их количество: cat /var/log/syslog | grep -c -i error.

Проверка: Запиши команду в файл ~/pentest/syslog_errors.sh и сделай его исполняемым chmod +x syslog_errors.sh.
Задача 2.3: Права доступа. Создай папку secret в /tmp командой mkdir /tmp/secret. Попробуй зайти в неё обычным пользователем (cd /tmp/secret). Потом смени владельца на root: sudo chown root:root /tmp/secret и права sudo chmod 700 /tmp/secret. Теперь попробуй войти — отказ? Понял магию прав.

Проверка: Напиши объяснение, что делают флаги chmod 754, в свой notes.txt.
Неделя 3: Bash-скриптинг для автоматизации
Задача 3.1: Напиши скрипт ping_sweep.sh, который принимает первый три октета IP (например, 192.168.1) и пингует все адреса от 1 до 254, выводя только живые хосты. Используй цикл for, ping -c 1 -W 1.

Проверка: Запусти ./ping_sweep.sh 192.168.1 в своей виртуальной сети (с разрешения!). Должен найти свой хост и шлюз.
Задача 3.2: Скрипт port_scan.sh, который принимает IP и диапазон портов (например, 1-1000), и с помощью /dev/tcp (bash-сокеты) проверяет открыт ли порт, выводя "Port X is open".

Ресурс: Гугли "bash tcp socket example".
Неделя 4: Работа с текстом и логами
Задача 4.1: Скачай любой лог-файл (например, образец access.log Apache из интернета). Используя awk, выведи топ-10 IP-адресов по количеству запросов: cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head.

Проверка: Объясни, что делает каждый элемент этого пайпа.
Задача 4.2: С помощью sed замени все вхождения "HTTP/1.1" на "HTTP/2.0" в копии файла лога.

Проверка: Примени команду и сохрани результат в новый файл.
