Месяц 1: Строим лабу
Задание: Собери лабораторию AD. Минимум:

Windows Server 2022 Evaluation – контроллер домена (DC).
Windows 10 Pro – клиент, введён в домен.
Настрой DNS, статические IP.
Создай несколько пользователей: обычный John, Jane, сервисный svc_sql.
Ресурс: "Building a Virtual Active Directory Lab" на Medium.
Месяц 2: BloodHound и разведка
Задание 2.1: Установи BloodHound (Community Edition) на Linux. На клиентском компьютере запусти SharpHound.exe (из-под пользователя John). Загрузи данные в BloodHound.
Задание 2.2: Изучи предустановленные запросы. "Find Shortest Paths to Domain Admins". Найди путь от John к Domain Admin. Назначь уязвимые ACL: дай пользователю Jane права GenericWrite на группу "Domain Admins". Снова собери данные и найди эту уязвимость.

Проверка: Сделай скриншот графа с путём атаки и объясни, как это эксплуатировать.
Месяц 3: Атаки на Kerberos
Задание 3.1: Kerberoasting. Создай сервисный аккаунт svc_mssql с простым паролем и SPN. Из-под пользователя John выполни Rubeus.exe kerberoast. Сохрани хеш, взломай его в Hashcat (hashcat -m 13100 hash.txt rockyou.txt). Получи пароль.
Задание 3.2: AS-REP Roasting. Найди пользователя без преаутентификации (или создай). Выполни Rubeus.exe asreproast и взломай хеш.
Задание 3.3: Golden Ticket. Скомпрометируй krbtgt хеш (DCSync). Создай Golden Ticket с помощью Mimikatz и получи доступ к любому ресурсу домена.

Ресурс: Статья "Kerberos Attacks Explained" наired.team.
Месяц 4: Латеральное перемещение
Задание 4.1: Настрой вторую Windows-машину в домене. Используй PsExec, WMI, WinRM для перемещения с одной на другую.
Задание 4.2: Pass-the-Hash. Извлеки NTLM-хеш локального админа. Используй его для аутентификации на другой машине, где этот пароль совпадает.
Задание 4.3: NTLM Relay. В лаборатории (изолированной!) запусти Responder для отравления LLMNR. Затем используй ntlmrelayx для ретрансляции хеша на целевую машину и выполнения команды.

Проверка: Напиши подробный отчёт по каждой атаке с описанием протоколов.
Месяц 5–6: Комплексная симуляция
Задание: Пройди виртуальную лабораторию "Attacktive Directory" на TryHackMe или машины HTB Pro Labs (RastaLabs, Offshore). Взломай всю сеть от рядового юзера до Domain Admin.

Цель: Получить флаг DA и составить полный отчёт.
