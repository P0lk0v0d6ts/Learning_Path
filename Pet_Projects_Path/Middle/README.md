# Middle projects

- [ ] **Автоматическое развёртывание лаборатории AD**
Vagrant + Ansible / Terraform: DC, два клиента, настроенные уязвимые ACL, сервисные аккаунты, SPN. Запускается одной командой.
- [ ] **Инструмент для Kerberoasting на C#**
Запрос TGS, извлечение хеша, сохранение в формате Hashcat. Обфускация строк.
- [ ] **Custom BloodHound queries (Cypher)**
Напиши коллекцию запросов для поиска сложных путей эскалации: владельцы групп, DACL abuse, Constrained Delegation.
- [ ] **Асинхронный C2 на Go**
HTTP/HTTPS транспорт, шифрование RC4/ChaCha20, поддержка команд: shell, upload/download, screenshot. Веб-панель на Vue.js.
- [ ] **Обход AMSI через PowerShell runspace**
Скрипт, который запускает вредоносный код в отдельном runspace с отключённым AMSI через рефлексию.
- [ ] **DLL Hijacking Hunter**
Сканер, который проверяет все пути поиска DLL для распространённых приложений и находит уязвимые (запись в папку, отсутствующая DLL).
- [ ] **Process Injection Utility**
На C++/C# с техниками: Classic DLL Injection, Process Hollowing, QueueUserAPC. Обход базовых сигнатур.
- [ ] **Keylogger с обходом Defender**
Получение нажатий через GetAsyncKeyState или Raw Input, обфускация строк, запуск из памяти.
- [ ] **Pass-the-Hash toolkit на Python**
Реализация NTLM аутентификации, SMB-подключения, выполнение команд через WMI (альтернатива impacket, но своими руками для понимания).
- [ ] **Kubernetes Pod Escape автоматизация**
Скрипт, который анализирует привилегии пода (hostPath, service account) и автоматически пытается сбежать на узел или получить секреты.
- [ ] **AWS IAM privilege escalation checker**
Перебирает разрешения текущей роли, находит пути эскалации (iam:CreatePolicyVersion, iam:PassRole) и выдаёт команды.
- [ ] **GraphQL атаки «из коробки»**
Скрипт на Python, который делает интроспекцию, ищет мутации, тестирует IDOR, инжекты в аргументы.
- [ ] **CI/CD Poisoning (GitHub Actions)**
Экспериментальная среда: репозиторий, в котором pull request может подменить скрипт сборки, украсть секреты. Разработай PoC.
- [ ] **Prometheus/Grafana scraper**
Сканирует открытые эндпоинты метрик, ищет секреты, внутренние IP, токены в лейблах.
- [ ] **Prompt Injection Scanner для LLM**
Набор автоматических тестов (обход системных инструкций, утечка данных, XSS через output) для любого API, совместимого с OpenAI.
- [ ] **EDR-невидимый контейнерный имплант**
На Go, который общается через DNS-over-HTTPS, маскируется под легитимный процесс, обходит Falco через уклонение от eBPF-хуков.
- [ ] **Фаззер для HTTP/2 и gRPC**
Инструмент для мутаций фреймов, проверки на HPACK-баги, переполнения буфера в заголовках.
- [ ] **Инструмент эксплуатации Java-десериализации**
Обёртка над ysoserial с собственной полезной нагрузкой (динамическое создание reverse-shell без внешних зависимостей).
- [ ] **Beacon для Sliver/Mythic с кастомным протоколом**
Разработай агента, который общается через WebSocket с маскировкой под обычный трафик (JSON-RPC).
- [ ] **Редактор Windows Event Logs**
Инструмент, который чистит или подделывает записи в Security.evtx (приостановка службы, прямое редактирование файла).
