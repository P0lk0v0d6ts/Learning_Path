Месяц 13–14: Windows Internals углублённо
Задание 13.1: Книга "Windows Internals Part 1". Прочитай главы о процессах, потоках, безопасности, виртуальной памяти. Обязательно запускай Process Explorer и смотри на всё вживую.
Задание 13.2: Практика: напиши программу на C, которая перечисляет процессы и их токены (используя Win32 API: OpenProcess, OpenProcessToken, GetTokenInformation). Это даст понимание, как работают хакерские инструменты.

Месяц 15–16: Эксплуатация ядра и драйверов (начало)
Задание 15.1: Настрой Windows 10 без обновлений (можно старую сборку). Найди публичный эксплоит для повышения привилегий (например, CVE-2020-0787, или другие LPE). Скомпилируй его и запусти на уязвимой машине, получи SYSTEM.
Задание 15.2: Изучи структуру шелл-кода. Напиши простой MessageBox shellcode для Windows x64 (с помощью msfvenom). Протестируй его в своём C-загрузчике.

Месяц 17–18: Обход защит
Задание: Создай лабу с Windows 10 и настроенным Защитником Windows.

Напиши PowerShell-скрипт, который выводит "Hello", но перед этим обойди AMSI (вставь известный сниппет).
Скомпилируй .NET assembly, который выполняет шелл-код в памяти, и обойди Defender, используя шифрование/обфускацию.
Ресурс: Sektor7 курсы по Malware Development или статьи ired.team.
