ML Model Reverse Engineering: Загрузи обученную модель (например, .pkl sklearn) с вредоносным кодом внутри (pickle injection). Проанализируй, как работает десериализация в ML-фреймворках.
Model Inversion & Extraction: Разработай атаку на модель, чтобы восстановить обучающие данные (хотя бы теоретически + PoC на простой нейросети).
Adversarial Evasion: Обмани классификатор изображений (Fast Gradient Sign Method) — создай «шумы», которые заставляют модель ошибаться.
