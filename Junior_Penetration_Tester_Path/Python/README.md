Неделя 9: Основы синтаксиса
Задание 9.1: Пройди интерактивный курс "Automate the Boring Stuff with Python" главы 0-6. Обязательно выполняй все упражнения в конце глав.

Проверка: Напиши программу, которая запрашивает у пользователя число N и выводит таблицу умножения на N в файл table.txt.
Задание 9.2: Словари и списки. Создай словарь services = {22:"SSH", 80:"HTTP", 443:"HTTPS"}. Напиши цикл, который спрашивает порт и выводит название сервиса или "Unknown".

Неделя 10: Работа с сетью
Задание 10.1: Модернизируй свой порт-сканер из bash. Напиши многопоточный сканер портов на Python, использующий threading или concurrent.futures. Пользователь задаёт IP и список портов через запятую.

Проверка: Просканируй Metasploitable, сравни скорость с однопоточным.
Задание 10.2: Напиши простой HTTP-клиент, который отправляет GET-запрос на http://example.com, выводит статус-код, заголовки и длину контента. Используй requests.

Неделя 11: Автоматизация веб-задач
Задание 11.1: Фаззер директорий. Используй requests и список common.txt из SecLists. Проверяй http://testphp.vulnweb.com/СЛОВО, выводи только ответы с кодом 200, 301, 403.

Проверка: Найди директории admin, images, secure.
Задание 11.2: Брутфорс логина. Найди на Metasploitable страницу phpMyAdmin или DVWA. Напиши скрипт, который перебирает пару логин:пароль из словаря и определяет успех по отсутствию фразы "Login failed".

Внимание: Делай задержку между попытками, не заддось локальную машину.
Неделя 12-14: Собственный проект
Задание: Создай инструмент "ReconBot". Он должен:

Принимать IP/домен.
Делать whois и dig запросы.
Сканировать топ 1000 портов через nmap (вызов subprocess).
Если найден веб-порт, запускать Gobuster.
Сохранять результаты в папку с именем цели и датой.
Проверка: Запусти на Metasploitable и покажи структуру отчёта.
