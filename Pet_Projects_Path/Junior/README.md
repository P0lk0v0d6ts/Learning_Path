# Junior projects

- **Многопоточный сканер портов на Python**
Используй socket, threading / asyncio. Определение сервисов по баннерам. Вывод в цвете.
- **Фаззер директорий и файлов**
Асинхронный HTTP-клиент, поддержка кодов ответов, рекурсия. Сделай CLI с argparse.
- **Сниффер пакетов на raw sockets**
Перехват Ethernet-фреймов, разбор IP/TCP/UDP заголовков, фильтр по портам — чистая образовательная практика.
- **Keylogger на Python (Windows/Linux)**
Через pynput или Windows API (SetWindowsHookEx). Отправка логов по email/Telegram.
- **Брутфорс SSH / FTP / HTTP Basic Auth**
Поддержка словарей, многопоточность, тайм-ауты, возобновление с последней позиции.
- **Инструмент для автоматической эксплуатации SQLi**
Union-based и error-based дамп таблиц. Используй requests + парсинг ответа.
- **Веб-шелл и панель управления**
Минималистичный PHP/ASPX/JSP шелл с файловым менеджером и выполнением команд. Сделай веб-интерфейс на Flask для управления.
- **ARP-спуфер и перехват трафика**
Скрипт на Python с scapy, который проводит MITM, пересылает пакеты и логирует HTTP-запросы.
- **Пассивный сборщик информации**
Скрипт, принимающий домен: whois, dig, Shodan API, crt.sh, находит поддомены, собирает email. Всё в структурированный JSON.
- **Расширение для Burp Suite**
Напиши плагин на Java (или Python через Jython), который генерирует payload'ы для SSTI или добавляет обход WAF (чередование регистров, пробелы).
- **Post-exploitation сборщик для Metasploit**
Meterpreter-скрипт, который делает sysinfo, hashdump, ищет SAM-файл, сохраняет результат в архив.
- **C2-канал через Telegram Bot**
Агент на Python, который принимает команды от твоего бота и отправляет результат. Шифрование AES.
- **Инструмент для пентеста Wi-Fi**
Автоматический захват PMKID и handshake, деаутентификация, подбор пароля через hashcat. Обёртка над aircrack-ng.
- **Анализатор уязвимостей по баннерам**
Парсит вывод Nmap XML, сопоставляет версии сервисов с CVE базой (NVD API). Генерирует список потенциальных уязвимостей.
- **Фишинг-фреймворк «одной кнопкой»**
Клонирует сайт (wget), поднимает HTTP-сервер, собирает введённые учётные данные, отправляет отчёт.
