Неделя 25: Установка и командная строка
Задание: Установи Windows 10 Pro (eval) в VirtualBox. Создай локального пользователя pentest без админских прав. Залогинься под ним.

whoami, whoami /all — изучи вывод.
net user — посмотри список пользователей.
net localgroup Администраторы — кто админ?
Проверка: Скопируй вывод whoami /all в отчёт, выдели SID и привилегии.
Неделя 26: Реестр и автозагрузка
Задание 26.1: Открой regedit. Найди ключ HKCU\Software\Microsoft\Windows\CurrentVersion\Run. Создай там строковый параметр "Test" со значением notepad.exe. Перезайди в систему — блокнот запустился.

Проверка: Удали параметр, проверь.
Задание 26.2: Используй PowerShell для поиска паролей в реестре: Get-ChildItem -Path HKLM:\ -Recurse -ErrorAction SilentlyContinue | Where-Object { $_.Name -match "password" }.

Неделя 27: Службы и процессы
Задание 27.1: Get-Service в PowerShell. Выведи все остановленные службы, режим запуска которых "Auto".

Задание 27.2: Скачай утилиту Sysinternals Suite. Запусти Process Explorer от админа. Найди процесс lsass.exe, зайди в свойства, Security. Увидь его токен и привилегии. Сделай скриншот.

Задание 27.3: Autoruns. Запусти от админа, изучи вкладку "Everything". Найди подозрительные записи (например, скрипты из временных папок). Пойми, где злоумышленник может закрепиться.

Неделя 28–30: Простейшая локальная эскалация
Лабораторная: Скачай машину "Windows 7" (если найдёшь) или "Hack The Box: Devel" (легкая машина Windows). Научись загружать веб-шелл (aspx) через FTP анонимный доступ, получать meterpreter-сессию и выполнять getsystem. Если HTB недоступен, используй Metasploitable 3 (Windows).

Задача: Эскалировать от локального пользователя до SYSTEM через модуль exploit/windows/local/ms10_015_kitrap0d или аналог.
Проверка: Документируй шаги и команды.
