# Senior projects

- **Собственный мультиплатформенный C2-фреймворк**
Сервер на Go (gRPC), агенты на C/C++/Rust для Windows, Linux, macOS. Динамическое управление конфигурацией, автоматическая генерация payload'ов под задачу.
- **LPE-эксплойт для ядра Linux**
На основе реального CVE (например, Dirty Pipe или более свежего). Напиши PoC с обходом KASLR, SMEP, SMAP.
- **Windows Kernel Shellcode (HEVD)**
Эксплуатация уязвимого драйвера HEVD: от IOCTL до SYSTEM-токена. Реализуй инжект в процесс.
- **UEFI Bootkit (исследовательский PoC)**
Модификация DXE-драйвера для загрузки до ОС. Только в изолированной среде, с глубоким пониманием Secure Boot.
- **Adversarial AI Toolkit**
Генератор возмущений для обхода ML-детекторов (изображения, сетевые пакеты). Включает FGSM, PGD и перенос на обход AV-моделей.
- **Golden SAML / Federation Hijack автоматизация**
Инструмент, который извлекает ADFS-сертификат, генерирует SAML-токен и проходит аутентификацию в Azure AD / Office 365.
- **Kubernetes Operator для скрытого майнинга**
Контроллер, который при обнаружении новых узлов запускает поды с майнером, маскируя их под системные. Исследование возможностей RBAC.
- **Supply chain attack: отравленный PyPI/NPM пакет**
Создай безобидный пакет, который демонстрирует внедрение бэкдора (телеметрия, удалённый доступ) при установке. Только для образовательного видео.
- **Service Mesh (Istio) traffic hijacking**
Инструмент, который использует уязвимости Envoy/мTLS для перехвата или подмены трафика между микросервисами.
- **Полный обход EDR через direct syscalls**
Библиотека на C, которая реализует все необходимые API через syscall-инструкции, минуя ntdll. Интеграция в C2.
- **Фреймворк для фаззинга протоколов**
Свой аналог Boofuzz, но с поддержкой асинхронных протоколов (MQTT, CoAP) и мутациями на основе ML.
- **Автоматический генератор отчётов**
Скрипт, который берёт выводы Metasploit/Nmap/Burp (XML/JSON) и генерирует готовый DOCX/LaTeX с графиками, Executive Summary и рекомендациями.
- **Платформа симуляции атак (Atomic Red Team расширение)**
Набор тестов на Python/Go, которые эмулируют техники MITRE ATT&CK с вариациями обхода, с автоматическим развёртыванием мишеней.
- **Сканер постквантовой уязвимости**
Инструмент, который анализирует TLS-сертификаты и определяет, используется ли классическая криптография (RSA, ECDSA), уязвимая к «собрать сейчас — расшифровать позже».
- **Red Team Lab-in-a-Box**
Полный Terraform-манифест, поднимающий в облаке мини-корпорацию: DC, ферма IIS, SQL Server, Linux-сервер, общие папки, всё с заранее внесёнными уязвимостями. Запускается одной командой и служит полигоном для тренировок.
