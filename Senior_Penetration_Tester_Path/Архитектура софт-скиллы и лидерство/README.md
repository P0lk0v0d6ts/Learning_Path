Задание 3.1: Провести 10 сложных проектов в роли ведущего пентестера.
Ты отвечаешь за Kick-off, распределение задач, общение с заказчиком, финальный отчёт. Собери шаблоны и методологии.
Задание 3.2: Менторство.
Возьми под крыло 2-3 джунов, составь им план, проверяй их работу. Научись объяснять сложное просто.
Задание 3.3: Выступление на конференции.
Выбери тему, в которой ты глубоко разобрался. Подай заявку на PHDays, ZeroNights, OffensiveCon. Напиши статью или white paper.
Задание 3.4: Создание open-source инструмента.
Это может быть фреймворк для фаззинга, скрипт для автоматизации разведки AD, или утилита для пост-эксплуатации. Важно качество кода, документация, тесты.
